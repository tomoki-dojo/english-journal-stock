```talk
クマ: Let's stop at a gasoline stand.
アーサー: A stand? Like a lemonade stand? | スタンド？ レモネード売りよるとこ？
クマ: レモネードはいらん！ガソリン入れたいんよ！
```

英語の stand は、屋台や売店のことです。

「gasoline stand」だと、道ばたでガソリンを売っている屋台みたいに聞こえてしまいます。

```balloon
アーサー: Gasoline lemonade… doesn't sound tasty. | ガソリン味のレモネード…美味しくなさそうやね
```

## ガソリンスタンドは英語で何て言う？

| 英語           | どこで   |
| -------------- | -------- |
| gas station    | アメリカ |
| petrol station | イギリス |

アメリカではガソリンを「gas」と言うので、gas station です。

イギリスでは「petrol」なので、petrol station になります。

ちなみに、アメリカの「gas」は気体のガスではなく、gasoline の略です。

```balloon
クマ: ガソリン＝ガス…最初は違和感ありますが、覚えてしまったら短いので日本でも言っちゃいそうです
```

## 給油のときの言い方

```phrases
Fill it up, please. | 満タンでお願いします
Regular, please. | レギュラーでお願いします
```

日本のフルサービスのスタンドなら、この 2 つでだいたい足ります。

ちなみに、アメリカのガソリンスタンドはセルフが多くて、先にお店で払ってから入れることもあります。

## 一緒に覚えたい言い方

- 給油する：**fill up** / **get gas**
- ハイオク：**premium**
- 軽油：**diesel**

```balloon
クマ: ちなみに外車がほぼハイオクなのは、ヨーロッパのレギュラーが日本のレギュラーよりオクタン価という値が高いから。日本のレギュラーだと足りないので、ハイオクを入れることになります
```

## 声に出して言ってみよう

旅先でレンタカーやバイクを借りたら、まず必要になる言い方です。

```phrases
Where is the nearest gas station? | 一番近いガソリンスタンドはどこですか？
Fill it up with regular, please. | レギュラー満タンでお願いします
I need to get gas. | ガソリン入れないと
```
