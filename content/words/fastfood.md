```talk
クマ: Potato, please!
アーサー: Just one potato? Raw? | じゃがいも1個？ 生で？
クマ: ちゃう！ 揚げたやつや！
```

英語の potato は「じゃがいも」そのものです。

フライドポテトは、アメリカでは **fries**、イギリスでは **chips** と言います。

```balloon
クマ: イギリスの「chips」がポテトなら、ポテトチップスは何て言うんだろう…と思ったら「crisps」でした
```

## 番号で注文する

```phrases
I'll have a number three. | 3番をください
Can I get a cheeseburger? | チーズバーガーをください
```

メニューに番号が振ってあるお店なら、番号で頼むのが一番ラクです。

## セットにする

```phrases
Make it a meal, please. | セットにしてください
Can I get a large fries? | ポテトのLをください
Can I get a Coke with that? | 飲み物はコーラで
```

日本の「セット」は、アメリカでは **meal** や **combo** と言います。

「Do you want to make it a meal?（セットにしますか？）」と聞かれることも多いです。

## 「〜抜きで」

```phrases
No pickles, please. | ピクルス抜きでお願いします
No ice, please. | 氷なしでお願いします
```

「〜抜きで」は「No 〜, please.」でシンプルに伝わります。

## 店内か、持ち帰りか

```phrases
For here, please. | 店内で
To go, please. | 持ち帰りで
```

カフェと同じく、ここはほぼ必ず聞かれます（[コチラの記事](/words/cafe-order)でも紹介しています）。

```balloon
アーサー: In the US, a "large" drink is really large. Be careful. | アメリカの「L」のドリンクは本気でデカいけん、気をつけて
```

## 声に出して言ってみよう

注文は早く言わないと後ろが詰まるので、口に慣らしておくと焦らずにすみます。

```phrases
I'll have a number three. | 3番をください
Make it a meal, please. | セットにしてください
No pickles, please. | ピクルス抜きでお願いします
```
