```talk
アーサー: Any bags to check? | 預ける荷物はありますか？
クマ: Check? …OK, please check my bag!
アーサー: Sure. Do you want me to look inside? | いいよ。中身見ようか？
クマ: 預けたいだけや！
```

check には「調べる」のほかに、「（荷物を）預ける」という意味があります。

なので空港で「Any bags to check?」と聞かれたら、「預ける荷物はありますか？」という意味なんですね。

```balloon
アーサー: Unless something's really off, nobody at the counter looks inside your bag, lol. | よほどのことがないと受付でバッグの中身をチェックすることはありません笑
```

## 預け荷物は checked baggage

| 英語            | 意味               |
| --------------- | ------------------ |
| checked baggage | 預け荷物           |
| carry-on        | 機内持ち込みの荷物 |

checked luggage と言っても大丈夫です。baggage と luggage はほぼ同じ意味です。

## カウンターで預ける

```phrases
I'd like to check this bag. | この荷物を預けたいです
This is my carry-on. | これは機内に持ち込みます
```

ちなみに、モバイルバッテリーは預け荷物に入れられません。

「Do you have any batteries in your bag?」と聞かれることもあるので、手荷物に移しておきましょう。

## 席を選ぶ

ついでに、「通路側の席」「窓側の席」という表現もチェックしておきましょう。

```phrases
Could I have an aisle seat? | 通路側の席にできますか？
Could I have a window seat? | 窓側の席にできますか？
```

aisle の s は読みません。「アイル」です。

```balloon
クマ: 「アイスル」って言いそうになるけど、愛さないです
```

## 重さを聞かれたとき

```phrases
Your bag is overweight. | 荷物が重量オーバーです
Is there an extra fee? | 追加料金はかかりますか？
```

## 声に出して言ってみよう

チェックインは旅のいちばん最初なので、ここがスッと言えると幸先がいいですよね。

```phrases
I'd like to check this bag. | この荷物を預けたいです
This is my carry-on. | これは機内に持ち込みます
Could I have an aisle seat? | 通路側の席にできますか？
```
