# クワガタ育成機能 アセット仕様書

`/roadmap`配下（クワガタ育成機能・アーサーの飼育部屋）用のイラスト素材仕様。対象アイテムの一覧・プラン・レア度は別ドキュメント（Claude Docs「クワガタ育成機能 画像素材リスト」）を参照。本書は制作時の技術仕様（サイズ・パーツ構成・ファイル名）をまとめる。

## 技術仕様（共通）

- **フォーマット**：パーツ分解が必要なもの（既知種・新種の生き物全般）はSVG推奨。パーツ分けが不要なもの（部屋背景、道具、水槽背景）はPNG（背景透過）でも可
- **制作解像度の考え方**：生き物・道具のような小さく表示されるパーツは「表示サイズ×4倍」で描いて縮小する方式（小さいサイズでも輪郭が潰れないようにするため）。部屋背景・水槽背景のような画面を覆う大きな1枚絵は「表示サイズ×2倍」（Retina対応分）で十分

### サイズ早見表

| アイテム | 画面上の表示サイズ | 制作解像度の目安 | 備考 |

### 道具・コルクボード・棚の表示サイズ

当初は全アイテム共通で「48px角の丸バッジに収める」想定だったが、実際に描いてもらった部屋背景の下書きでは、コルクボードや棚のように部屋に根付いた大きな物と、霧吹き・虫眼鏡のような手に持つ小物とでスケール差が大きいことがわかったため、**アイテムごとに表示幅（部屋の横幅に対する%）を変える**方式に変更した。縦横比は各アイテムの原画に任せる（`object-contain`、正方形キャンバスに収める必要はない）。

| アイテム | 部屋幅に対する表示幅の目安 | 備考 |
| --- | --- | --- |
| Stage0（虫眼鏡） | 約11% | |
| Stage1（虫カゴ） | 約18% | |
| Stage2（霧吹き） | 約7% | |
| Stage3（温湿度計） | 約8% | 未着手・暫定値 |
| Stage4（ピンセット） | 約7% | 未着手・暫定値 |
| Stage5（顕微鏡） | 約11% | 未着手・暫定値 |
| コルクボード | 約30% | 下書きの中で最も大きい物 |
| 棚 | 約16% | 縦長で部屋の高さいっぱいに近い想定。横幅の%はあくまで目安で、縦は原画の縦横比に追従する |

上記はユーザーが描いた部屋背景の下書き（1枚目）から実測した値を初期設定として`roadmap-room.tsx`の`ITEM_PLACEMENT`に反映済み。実イラストが揃うタイミングで、実際の見え方に合わせて微調整してよい。

制作解像度の目安は「その表示幅（PC最大720px時の実寸px）の3〜4倍」。例えばStage1（表示幅18%≒PCで約130px）なら390〜520px角程度、コルクボード（30%≒約216px）なら650〜860px角程度を目安にするとよい。

### 部屋背景の縦横比について

部屋カードの横幅はスマホ（約320〜380px）とPC（コンテナ最大幅720px）で2倍以上差がある。背景を16:9のような横長固定にすると、`object-fit: cover`で画面幅ごとに切り取られる範囲がズレて、スマホとPCで道具の見え方（どこまで画面に収まるか）が変わってしまう。そこでCSSの`aspect-ratio`で縦横比そのものを固定し、幅に連動して高さも伸縮させることで、どの画面幅でも常に同じ構図が見えるようにしている（coverによる切り取りが発生しない）。

比率の選定は、1:1（正方形）・4:3・16:9の3パターンを実際の表示px換算で比較して決めた。

| 比率 | スマホ（幅330px想定） | PC（幅720px） | 傾向 |
| --- | --- | --- | --- |
| 16:9 | 330×186px | 720×405px | スマホで縦が狭すぎ、道具8個を散らす余白が足りない |
| 1:1（正方形） | 330×330px | 720×720px | スマホはちょうどよいが、PCは縦に間延びしてスクロールが増える |
| **4:3（採用）** | 330×248px | 720×540px | スマホは8個の道具を置くのに十分な高さを確保しつつ、PCの縦の間延びも抑えた中間点 |

結論として4:3を採用。実装は`roadmap-room.tsx`の部屋コンテナに`aspect-[4/3]`を指定している。将来、実際に手描きの部屋イラストが入って見え方を確認した上で、必要なら3:2寄りなどに微調整してもよい。

### 水槽内デコレーション（置物）※未着手・方針メモ

水槽を覗き込んだときに何も入っていないと寂しいため、石・枝・落ち葉・水草などの小物を背景内に配置する。クワたん本体より奥（背景寄り）に表示し、手前をクワたんが歩いているように見せる想定。

- **Free/Proの差別化方針**：Free＝デコレーション2種、Pro＝＋デコレーション3〜4種（Proはプールが2種に3〜4種追加されて計5〜6種になり、水槽ごとの見た目バリエーションが豊かになる）
- アクアリウム区画（エリア4）はそもそも区画自体がPro限定（#260で実装済み）なので、上記の差別化はテラリウム側（Free/Pro共通エリア）に対するもの
- 表示する組み合わせは開くたびに変わらないよう、水槽の`speciesId`からシード付き乱数で決定的に選ぶ方式を想定（`hashHue`と同じ考え方）。1水槽につき1〜3個を配置
- ファイル名は`room_item_*`と同じ命名ルールに揃えて`tank_item_[name].svg`、配置先は`public/roadmap/tank/`直下（`tank_bg_*`と同じフォルダ）
- 制作済み：`tank_item_stone.svg`（石）・`tank_item_food.svg`（エサ）の2種→そのままFree用デコレーションプールとして使う想定
- 実装は「水槽の置物の追加制作と表示の実装」タスクで行う（#261は完了済み）

## 既知種の成長段階アート（卵・幼虫・蛹・成虫）

既知種5種（エークワたん・ヒビクワたん・シャベクワたん・フルクワたん・テッペンクワたん）は`stage_clear`で確定入手＝「卵から育てる」設定のため、取得からの経過日数で卵→幼虫→蛹→成虫と自動的に成長する（`kuwagata.ts`の`getIndividualGrowthStage`、「経過日数＋ブースト日数」が1日未満→卵、4日未満→幼虫、7日未満→蛹、以降成虫）。ブースト日数（`kuwagata_individuals.boost_days`）は、Stage0〜4で項目を初めて習得済みにするたびに育成中の全個体へ加算される（`KUWAGATA_GRADUATION_BOOST_DAYS`）。テッペンクワたん（KW-0004）だけは、日数がたっても蛹で止まり（ゲージは満タンのまま）、Stage5を卒業して初めて成虫になる。卒業後に部屋へ入ると、専用の羽化の演出（羽化前の姿が震える→白い閃光→光線の中に成虫が登場＋紙吹雪、「Stage5卒業！テッペンクワたんが◯◯から成長して、成虫に羽化した！」。◯◯は羽化直前の段階＝`hatched_from`）が一度だけ出る（`kuwagata_individuals.hatch_celebrated_at`で既読管理）。ログイン時の豆知識を読むと、1日1回、育成中の全個体に+0.1日のログインブースト（`login_boost_days`）が入る。棚の拡大表示の個体リストに、次の段階へのゲージ（経過日数分＝アンバー、ログインブースト分＝オレンジ、練習のブースト分＝青）が出る。新種（`roll`＝野生採集）は採集した時点で既に成虫という設定にしたため対象外（採集時に`hatched_at`を即セットする実装に修正済み）。

5種それぞれ、以下4状態の絵が必要（5種×4状態＝20枚、既存の成虫パーツ一式とは別に卵・幼虫・蛹の3状態＝15枚が追加分）。

| 状態 | 必要な絵 | 制作解像度 |
| --- | --- | --- |
| 卵 | 静止画1枚（向き・脚なし） | 112px角 |
| 幼虫 | 体節3パーツ（頭・胴体前半・胴体後半）、向きは1種類のみ。くねりアニメーション対象 | 112px角 |
| 蛹 | 静止画1枚（向き・脚なし） | 112px角 |
| 成虫 | 既存の既知種パーツ構成どおり（本体・大顎・脚6本・前後向き） | 112px角 |

ファイル名：`kuwagata_[code]_egg.svg` / `kuwagata_[code]_larva_head.svg` / `kuwagata_[code]_larva_body_front.svg` / `kuwagata_[code]_larva_body_rear.svg` / `kuwagata_[code]_pupa.svg`（`[code]`はKW-0001などの種コード）。

幼虫は見た目上、前向き/後ろ向きの描き分けがほぼ不可能なため1方向のみ（成虫のような`facing`切り替えはしない）。一方で「このアプリ内では幼虫も地上に出ている」という世界観に合わせ、成虫と同じくセーフティゾーン内をゆっくり歩き回らせる（`WanderingCreature`/`useWander`をそのまま再利用し、脚の代わりに体節を動かす）。脚のように歩行で前後移動させるのではなく、頭→胴体前半→胴体後半の順に少しずつ位相をずらして回転させる「くねり」アニメーション（`kuwagata-larva-wriggle`、脚の`kuwagata-leg-sway`と同じ仕組みを体節に転用）で表現する。絵は左向き1方向のみなので、右へ進むときだけ左右反転する。

卵と蛹は歩き回らず、その場に置いたまま、ときどき短くピクピク震える（`kuwagata-egg-twitch`/`kuwagata-pupa-twitch`。大半は静止して数秒に一度だけ2〜3回震える間欠アニメで、個体ごとに位相をずらして同期させない）。置き場所は置物や他の個体を避けて個体IDから決定的に決める。

**実装状況**：エークワたん（KW-0001）・ヒビクワたん（KW-0002、背中に波紋模様）・シャベクワたん（KW-0003）・フルクワたん（KW-0008）・テッペンクワたん（KW-0004）は成虫・卵・幼虫・蛹とも制作・実装済み（`KNOWN_CREATURE_ART`/`KNOWN_STAGE_ART`）。既知種5種すべての絵が揃った。絵が無い種・段階は成虫のアートにフォールバックする。

テッペンクワたんはStage5解放時に卵で入手→卒業時に強制的に成虫へ羽化する特別演出があるが、絵の必要数は他の既知種と同じ4状態（卒業前に蛹の状態を経由して見せるかはUI実装側の判断、新種の描画コード実装タスクで対応）。

## 脚・羽根のアンカー基準（アニメーション対応）

歩行・羽ばたきはキーフレーム画像の差し替えではなく、1枚の絵をCSSの`transform-origin`＋`transform: rotate(...)`で角度を振って動かす方式（追加ライブラリ不要）。そのため、パーツ分けする際は以下を守って書き出す。

- **脚**：エークワたん正面の試作で確認した結果、この俯瞰角度では奥側（右）の脚は2本が本体の陰に隠れて1本しか見えないことが判明。そのため左右非対称の構成に変更した。
  - 左脚（手前側）：3本とも別ファイルのまま（`leg_L1`/`leg_L2`/`leg_L3`）。実装は各パーツを個別の`<img>`として読み込みCSSで個別に`transform`をかける方式のため、1ファイルにまとめると内部の脚を個別に動かせなくなり「3本が完全に同じタイミング・角度で一斉に動く」不自然な見た目になってしまう。別ファイルにしておけば、各脚に少しずつ違うタイミング・振れ幅を与えて自然な歩行に見せられる（検討の経緯：当初1ファイルにまとめる案を出したが、不自然になるとの指摘で撤回）
  - 右脚（奥側）：見えている1本だけを独立パーツにする（`leg_R`）。隠れる2本は描かない
  - 歩行時は左脚3本と右脚1本を逆位相（片方が前に出ている間、もう片方は後ろ）で角度を振り、左脚3本の間にも少しタイミングをずらして自然さを出す想定
- **羽根**：同様に、本体との付け根を羽根レイヤーの回転基準点に合わせる。羽ばたきは開閉（角度を往復）で表現する想定
- **大顎（既知種のみ）**：個体差バリエーションとしてパーツ単位で複数パターン用意し、丸ごと差し替える方式（アニメーションの対象ではない）
- **幼虫の体節**：頭・胴体前半・胴体後半の3パーツに分け、それぞれの付け根（隣の体節との境目）を回転基準点にする。脚と同じく個別の`<img>`として重ね、頭→前半→後半の順にタイミングをずらして回転させることで「くねり」を表現する。基準点（キャンバス112pxに対する%）と振れ幅はエークワたんで目測した値（`KNOWN_STAGE_ART`、頭40%/59%・±3°、胴体前半31%/54%・±2.5°、胴体後半49%/55%・±4°）で、新しい種でも絵に合わせて調整する

## 水槽の表示仕様（匹数・分割・名前）

- **1種類=1水槽**：既知種・新種とも、種類ごとに専用の水槽（エークワたんの水槽、シャベクワたんの水槽…）。複数種を1つの水槽にまとめることはしない。既知種はFree/Proを問わず常に全部表示（Freeの表示枠上限は新種の「種類数」だけが対象）。
- **1水槽6匹まで**：拡大表示で歩き回るのが気持ちよく収まるのは5〜6匹まで（置物と衝突回避を考えた限界）。同じ種類が6匹を超えたら、捕まえた順に次の水槽へ繰り上げる（`kuwagata.ts`の`KUWAGATA_TANK_CAPACITY`、水槽ごとに`tankId`・`partNumber`）。
- **棚の一覧は1種類1枚のカード**：同じ種類が複数水槽に分かれても、カードは1枚（匹数は全水槽の合計、代表の絵は一番大きい個体）。水槽の切り替えは拡大表示の中のページャ（「‹ 1 / 2 ›」）で行う。カードの枚数は種類数（既知種5＋新種38）で頭打ちになる。
- **衝突回避**：クワたん同士・置物とは、次の目的地を選ぶ時点で、スプライトの実サイズ（`widthPct`）と水槽コンテナの縦横比（4:3）を考慮した距離で避ける。移動中のすれ違いまでは避けない（そこまでやると経路探索が必要になるため割り切り）。
- **名前**：個体に名前を付けられる（`kuwagata_individuals.nickname`、NULL可、1〜10文字のCHECK制約）。未命名のデフォルト表示は種類名（最長は「テッペンクワたん」の8文字）。拡大表示のリストの鉛筆アイコンから編集し、水槽内では歩いている個体の頭上に小さな白い丸ラベルで表示する。保存は`POST /api/roadmap/kuwagata/nickname`（本人の個体のみ更新可）。

## 成虫の成長（大きさ）※実装済み

成虫になった個体にも、練習のご褒美が効くようにする。成虫になる前は「成長日数」、成虫になった後は「大きさ」が進む。

- **対象**: 成虫の全個体（既知種・野生採集の新種とも）。「相棒」のような選択はなし。テッペンクワたんはStage5卒業で成虫になった後から対象。
- **ご褒美の元**: フレーズを新たに卒業したとき。重みは成長日数と同じ（Stage0/1=0.05、Stage2=0.1、Stage3=0.2、Stage4=0.4）を「成長ポイント」として累積する。ログインのご褒美は大きさには効かせない。Stage5は卒業しても加算しない（既存のブーストと同じ扱い）。
- **見せ方**: 5段階のサイズレベル（Lv0〜Lv5）。レベルが上がるときに演出を出す。連続的な拡大はしない。
- **基準サイズ**: 種類ごとに `kuwagata_species.base_size` を持つ（既定1.0、テッペンクワたん1.2）。タマゴから育てた個体の`size_scale`は基準サイズ固定、野生で採集した個体は基準サイズの±10%でばらつく（テッペンの野生は1.08〜1.32）。
- **倍率**: 元のサイズ（`size_scale`）に、レベルごとに +6%（Lv5で +30%）を掛ける。テッペンの野生の最大個体で 1.32×1.3＝約**1.72倍**（水槽の幅の約17%）が最大。
- **レベルの閾値（初期値・調整前提）**: Lv1=1pt、Lv2=3pt、Lv3=6pt、Lv4=10pt、Lv5=15pt。5段階すべて到達まで、練習を続けて約2〜3か月が目安。
- **データ**: `kuwagata_individuals` に成長ポイント列（仮: `size_growth_points`）を追加し、`add_kuwagata_boost` と同じ要領で成虫の全個体に加算するRPCを作る。表示サイズ＝`size_scale × (1 + 0.06 × Lv)`。
- **表示**: 結果画面のパネルに、成虫の大きさゲージ（緑系。成長日数のゲージとは別色）も出す。棚の個体リストにサイズレベルも出す。レベルアップの演出は、結果画面または部屋に入ったときに出す。
- **水槽の幅**: 倍率に比例（1.0倍＝水槽の幅の10%、`creatureWidthPct`）。種類ごとのsize_scaleの差もレベルの差もそのまま見た目に出す方針に変更した。実機確認の結果、最大約17%（1.72倍）は、6匹がばらけて歩ければ問題なし（約20%は大きすぎ）。歩ける範囲は天面のほぼ全体（縁から0.08内側）で、大きい虫ほど左右の端に寄れない（`pickRandomSpot`）。

## フルクワたんの「ファイティングポーズ」

フルクワたん（KW-0008）の成虫は、12秒に1回・3秒間、体を前にかがめて小刻みに構え、大顎をガチガチ開閉する（`useFighting`、`kuwagata-fight-pose`/`kuwagata-fight-jaw`）。個体ごとに開始のタイミングをずらして、一斉には構えない。成虫のみが対象。絵の追加は不要（既存の成虫アートをCSSで動かすだけ）。

## テッペンクワたんの「てっぺんポーズ」

テッペンクワたん（KW-0004）の成虫は、14秒に1回・3秒間、すっと背伸びして胸を張り、頭上にきらきら（✦×3）が瞬く（`useTimedGesture`、`kuwagata-proud`、きらきらは`animate-egg-twinkle`を流用）。個体ごとに開始のタイミングをずらす。成虫のみが対象。絵の追加は不要。

## シャベクワたんの「喋る仕草」

シャベクワたん（KW-0003）は、同じ水槽に他の個体がいるときだけ、15秒に1回・3秒間、体を小さく左右に揺らして頭上に丸い吹き出しを出す（中身は「…」40%・「♪」「♡」「？」20%ずつの重み付きランダム）（`useChatter`、`kuwagata-chat-wobble`/`kuwagata-chat-dot`）。個体ごとに開始のタイミングをずらして、一斉には喋らない。成虫のみが対象（卵・幼虫・蛹は喋らない）。1匹だけの水槽では出ない。絵の追加は不要（既存の成虫アートをCSSで動かすだけ）。
