# Shorts #6 台本「Let's table this.」

企画メモ（`_reference/shorts-content-plan.md`）のネタ#6に対応。1〜5本目のフォーマットを踏襲（前回ラストの次回予告テロップ回収→フリ→反応→クマのトンチンカン決め台詞→同僚の冷静な反応→種明かし→予告）。
ただし今回は「米＝保留／英＝今すぐ話す」で意味が正反対になるネタのため、5本目の台本メモで保留にしていた「もう一人キャラを出すか」を採用する。新たに同僚B（イギリス出身設定）を初登場させ、同僚Aとの解釈違いでクマが板挟みになる構成にする。
**（テロップ案訂正版）** 初稿から以下2点を変更：①クマ自身が「決め台詞」を言う構成をやめ、同僚AとB自身が対立する英語の決め台詞（"Drop it!" / "Discuss it!"）を叫び合う構成に変更。②スマホ検索での種明かしビートを廃し、同僚同士の言い合いを聞いてクマが自力で意味の違いに気づく構成に短縮。

## 基本情報

- シーン：会議（会議室、資料を挟んだ打ち合わせ）。同僚A（アメリカ出身設定・1〜5本目と同一人物）＋同僚B（イギリス出身設定・**今回初登場**）＋クマの3人芝居
- 話者ルール：同僚A・同僚Bは全編英語。クマは日本語ベースで、決め台詞など要所のみ英語
- 謎フレーズ：**"Let's table this."**
- 意味：米国英語＝この件は一旦保留にしよう／英国英語＝この件は今すぐ話し合おう（正反対）
- オチの方向性：同僚Aの「保留にしよう」のつもりの一言に対し、同僚Bが「え、今すぐ話すってこと？」と真逆の解釈で食いついてしまい、クマは資料を出すべきか片付けるべきか分からず立ち尽くす
- 決め台詞パターン：**対立叫び型（今回のみの新パターン）**（1本目の空とぼけ型、2本目の勘違い直球型、3本目の椅子スピン型、4・5本目のモノボケ型とは別パターン。クマ自身は勘違いせず、同僚AとBがそれぞれ英語の決め台詞「Drop it!」「Discuss it!」を叫んで対立し、クマは板挟みで立ち尽くすだけの役回りになる）
- 新規追加ビート／変更点：他話にある「クマがスマホで検索して種明かし」のビートを今回は省略し、代わりに同僚AとBの言い合い（"...Wait, table means we drop it, right?" / "...No, table means we discuss it right now."）を聞いたクマが自力で「なるほど、米英で意味が逆なのか」と気づく構成にする。掛け合いのテンポを詰めて尺を圧縮する狙い。
- 尺目安：25〜30秒
- 開口一番の言語：3本目からの方針を継続し、クマの日本語から開始する
- 前回（5本目）ラストの次回予告「机に置くのか？片付けるのか！？」をそのまま回収する構成

## 台本

### ① フック（0〜2秒）

前回ラストの次回予告テロップをそのまま回収する形で開く（5本目ラストの予告に対応）。カットは会議室、クマが資料の束を抱えたまま入り口で固まっている引き絵。

> テロップ：「机に置くのか？片付けるのか！？」

### ② 本編

**状況のフリ（〜8秒・クマのアップから始める）**：

クマ（資料を抱えたまま会議室を覗き込み、日本語）：**「さっきの話、どうしよう…置いとくか今日話すのか、まだ決まってないけど…」**

（→ 1・3・4・5本目と同じく、クマの短い独り言として完結させる。5本目ラストの「書いて伝えますね」を受けて、資料自体はすでに用意できている、という前提を一言で共有する）

**同僚Aの反応（英語キーフレーズ・アメリカ出身設定）**：

同僚A（軽く手を振りながら）：**"Don't worry about it now — let's table this."**
（テロップ：今は気にしなくていいよ、これは一旦保留にしよう）

**同僚Bの割り込み（英語・イギリス出身設定、今回初登場）**：

同僚B（急に身を乗り出して）：**"Table this? Brilliant, let's get straight into it, then."**
（テロップ：ん、今すぐ話し合おうってこと？それはいいね、早速始めよう）

**クマ、無言でフリーズ（セリフなし）**：

クマ（資料を出そうとしたり戻そうとしたりを繰り返しながら、目が泳ぐ）：（…セリフなし、表情のみ）

**同僚AとB、決め台詞で対立（それぞれ英語で叫ぶ）**：

同僚A（資料を押し戻しながら）：**"Drop it!"**
（テロップ：保留！）

同僚B（資料を引き寄せながら）：**"Discuss it!"**
（テロップ：話し合う！）

**同僚Aと同僚Bが同時に真顔でお互いを見る**：

同僚A：**"...Wait, table means we drop it, right?"**
（テロップ：待って、table って保留にするって意味だよね？）

同僚B：**"...No, table means we discuss it right now."**
（テロップ：いや、table って今すぐ話し合うって意味でしょ）

### ③ 種明かし（今回は検索シーンなし）

**クマ、困惑の心の声（日本語）**：

クマ（内心、資料を抱えたまま）：**「テーブルイットってどういうこと…？」**

**クマ、自力で納得（心の声・日本語）**：

クマ（内心、ハッとした顔で）：**「なるほど、アメリカとイギリスで保留と話し合うの意味が逆になるのか…」**

**同僚AとBの着地（テロップのみ・音声不要）**：

同僚A・同僚B、顔を見合わせて同時に：**"...Let's just email everyone the decision."**
（テロップ：…結局、決定事項はメールで送ろうか）

### ④ 次回予告

**クマの＋αの一言（アイキャッチ・今回はクマ側から、他話の「同僚の+αコメント」に相当する位置）**：

クマ（資料を抱えたまま、疲れた顔で日本語）：**「もう、資料は一旦しまいます…」**

**次回タイトル（日本語のみ・煽り、シーンの最終カット）**：

テロップ：「次回：収穫はじめます！？」

## CTA・安全マージン

- 本編中は宣伝なし（1〜5本目方針を踏襲）。次回予告の終盤にのみ「他の表現はアプリでチェック」を小さく添える。
- テロップ・CTAは画面下部・右側の操作ボタン帯を避けて中央〜上寄りに配置する（1本目で指摘したShorts UIとの重なり対策を継続）。
- 概要欄には1〜5本目と同様、Webアプリへのリンクのみ設置（`https://app.upskillenglish.bear-fruit.online`）。概要欄本文は別途作成する。
- **今回のみの制作留意点**：同僚Bが今回初登場。同僚Aと見分けがつくよう、服装や髪型など最低限の差分デザインが必要（バストアップのみなので簡易な差分で可）。声質・話速も同僚Aと変える。
- 尺が他話（25〜30秒）よりやや伸びやすい構成（3人の掛け合いのため）。同僚AとBのセリフはテンポよく畳みかけ、間を詰めて尺を圧縮すること。検索シーンを省いた分、他話より尺には余裕が出る見込み。
- クマの心の声（テロップ⑩・⑪）は表示時間をやや長め（他話+0.5秒程度）に取り、米英の意味が逆転するオチを視聴者が読み切れるようにする。
